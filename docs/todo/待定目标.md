## 手写输入：迁移至 Google ML Kit Digital Ink Recognition

当前搜狗手写 SDK 的 `license.temp` 授权绑定了语燕包名，`dev.yeying.ime` 无法通过验证（`initWithDirectory` 返回 false）。

**方案：** 替换为 [Google ML Kit Digital Ink Recognition](https://developers.google.com/ml-kit/vision/digital-ink-recognition/android)

- 复杂度低：API 简洁，收集 Stroke 点阵 → recognize() → 候选词
- 性能：完全在设备端运行，无需网络
- 体积：SDK 基础库 ~2MB 打进 APK，中文模型 ~20MB 首次使用时按需下载
- 可同时移除搜狗 native 库（~12MB）和 hw/ 数据文件（~8MB），APK 反而更小

**实现要点：**
- 依赖：`com.google.mlkit:digital-ink-recognition:19.0.0`
- 下载中文模型：`DigitalInkRecognition.getModel(ChineseScript.identifier)`
- HandwritingBoard 的 Offset 转为 ML Kit 的 `Ink.Point` / `Ink.Stroke`
- 首次切换手写时触发模型下载，下载完成后启用画布
