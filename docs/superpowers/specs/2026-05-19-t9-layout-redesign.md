# T9 九键布局重设计

## 目标

修复当前拼音9键布局的 bug 并重构为三列布局，参考 yuyan 输入法默认九键布局。

## 当前问题

- `T9Layout.row1` 中 `1` 和 `ABC` 之间多出一个 `'` 键（`KEYCODE_QUOTE`）
- 布局为传统 4 行均匀排列，无左右侧栏
- 无底部留白适配曲面屏手机

## 目标布局

```
┌─────────────────────────────────────────┐
│ ，  │  1  ABC  DEF  │  ⌫  │
│ 。  │  GHI JKL  MNO  │  重输 │
│ ？  │  PQRS TUV WXYZ │  @  │
│ ！  │                │     │
├─────┴────────────────┴─────┤
│ 符号 │ 123 │  空格  │中/英│ 确认 │
├───────────────────────────────┤
│         留白区域              │
└───────────────────────────────┘
```

### 主区域（三列结构）

**左列 — 标点符号（4键，竖排）：**
| 键 | 功能 |
|----|------|
| ， | 输入逗号 |
| 。 | 输入句号 |
| ？ | 输入问号 |
| ！ | 输入感叹号 |

4 键总高度与中间九键 3 行齐平。

**中列 — 九键网格（3x3）：**
| 行 | 键 |
|----|-----|
| 1 | 1, ABC(2), DEF(3) |
| 2 | GHI(4), JKL(5), MNO(6) |
| 3 | PQRS(7), TUV(8), WXYZ(9) |

**右列 — 功能键（3键，竖排）：**
| 键 | 功能 |
|----|------|
| ⌫ | 删除（KEYCODE_DELETE，可重复触发） |
| 重输 | 清除当前组合输入（ClearComposition） |
| @ | 输入 @ 符号 |

3 键总高度与中间九键 3 行齐平。

### 底部工具栏

| 键 | 功能 |
|----|------|
| 符号 | 切换到 SYMBOL 键盘 |
| 123 | 切换到 SYMBOL 键盘 |
| 空格 | 输入空格 |
| 中/英 | 切换键盘类型（T9 ↔ QWERTY/ENGLISH） |
| 确认 | 回车键（KEYCODE_ENTER） |

### 底部留白

- 工具栏下方增加留白区域
- 适配曲面屏手机底部弯曲部分
- 后续可扩展为"历史剪切板"等功能

## 涉及文件

| 文件 | 改动 |
|------|------|
| `T9Layout.kt` | 重写布局数据：移除 `'` 键，重构为三列+底栏+留白 |
| `T9Keyboard.kt` | 重写 Composable：三列布局（左标点 + 中九键 + 右功能） |
| `KeyboardViewModel.kt` | 添加 `中/英` 切换处理 |
| `KeyboardState.kt` | 可能需要新增 key code 常量 |

## 关键实现细节

1. **三列对齐**：左列 4 键使用 `fillMaxHeight` + `weight(1f)` 等分高度，确保与九键 3 行齐平；右列 3 键每键等同九键一行高度
2. **删除键**：保留 `isRepeatable` 长按重复删除行为
3. **中/英切换**：在 T9 和 QWERTY 键盘之间切换，复用 `KeyboardAction.SwitchKeyboard`
4. **底部留白**：固定高度的 `Spacer`，约 24-32dp

## 不在范围内

- 留白区域的"历史剪切板"功能（后续实现）
- 其他键盘类型（QWERTY、手写等）的布局调整
